# Spieldose — Swiss Music Box

A Swiss music box branding of Simon Willison’s Scrimshaw Jukebox. Only the title, copy and visual styling were changed; the music, scores, synthesizer and playback are unchanged.

Upstream source: https://github.com/simonw/tools/blob/main/scrimshaw-jukebox.html
