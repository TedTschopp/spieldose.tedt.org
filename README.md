# Spieldose — Swiss Music Box

A Swiss music box branding of Simon Willison’s Scrimshaw Jukebox. The title, copy, visual styling and an additional comparison illustration have been adapted; the music, scores, synthesizer and playback are unchanged.

An experimental pixel-art Swiss alpine village is displayed below the original harbour for comparison. Both scenes remain visible while the alpine design is refined; the new renderer reads audio energy for window lighting without changing playback.

Upstream source: https://github.com/simonw/tools/blob/main/scrimshaw-jukebox.html
